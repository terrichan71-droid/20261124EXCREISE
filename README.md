# MP3 語音轉文字 → Word

這是一個使用 Streamlit 和 OpenAI Whisper 的語音轉文字工具。

## 功能

- 上傳 MP3 語音檔
- 使用 Whisper 將語音轉為文字
- 支援中文／粵語轉錄
- 生成 Word (.docx) 檔案
- 直接從網頁下載 Word 檔

## 使用方式

1. 開啟 Streamlit 網頁
2. 上傳 MP3 檔案
3. 選擇 Whisper 模型
4. 點擊「開始語音轉文字」
5. 下載生成的 Word 檔案

## 技術

- Python
- Streamlit
- OpenAI Whisper
- python-docx
